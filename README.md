# NoBS
Focused on making LLMs answer exactly what the users ask, without unnecessary jargon, excessive explanations, unsolicited advice, or imposed judgements The goal is simple: say no more than necessary

# Personal problem: What am I facing?

Using LLMs like ChatGPT, Claude, DeepSeek, Google Gemini, and others, I have noticed certain patterns in their responses that disrupt the natural flow of interaction.
These behaviours introduce unnecessary complexity and friction:

* Overexplaining simple questions
* Using unnecessary jargon
* Taking detours instead of answering directly
* Giving unsolicited advice
* Adding unnecessary warnings and disclaimers
* Imposing unwanted opinions and judgments
* Being preachy
* Overthinking simple tasks
* Overcomplicating straightforward requests
* Repeating the same information
* Unnecessary clarifying questions
* Trying to perfect beyond what's needed
* Asking follow-up questions without being prompted
